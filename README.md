# 청년부 주보

React와 Electron으로 만든 Windows 주보 작성 앱입니다. PowerPoint 원본 서식을 유지해 PPT와 PDF를 만듭니다.

## 설치 및 업데이트

[최신 릴리스](https://github.com/Mellow1213/youth-bulletin/releases/latest)에서 `YouthBulletin-Setup` 설치 파일을 실행하세요. Windows 10/11 64비트와 데스크톱 Microsoft PowerPoint가 필요합니다.

앱을 시작하면 새 릴리스를 확인합니다. 새 버전 알림에서 내려받은 뒤 **저장 후 업데이트**를 누르면 자료를 자동 백업하고 설치 후 다시 시작합니다. 인터넷 연결이 없어도 편집은 계속할 수 있습니다. 환경설정 → 업데이트에서도 확인할 수 있습니다.

기존 휴대용 버전 사용자는 기존 앱의 **환경설정 → 자료 백업·복원 → 자료 백업하기**로 먼저 백업한 뒤, 설치형 앱에서 복원하세요. 설치형 앱 자료는 `%APPDATA%\YouthBulletinReact`에 저장됩니다. 설치 파일에는 개인 명단과 작성 자료가 포함되지 않습니다.

## 개인 자료

처음 설치하면 생일·셀 명단이 비어 있습니다. 환경설정에서 한 번 등록하거나 개인 백업 파일을 복원하세요. 설교자·찬양팀도 환경설정 → 저장·환경 점검에서 한 번 설정합니다. 앱 업데이트는 사용자 자료와 분리됩니다. 백업 파일은 공개 저장소에 올리지 마세요.

Google Drive 자료 연결은 아직 구현되지 않았습니다. 현재는 백업·복원을 사용합니다. 앱에는 GitHub 토큰이나 Drive 인증 정보가 들어 있지 않습니다.

## 개발 및 릴리스

Node.js 24 및 Windows에서 `npm ci`, `npm test`, `npm run package:installer`를 실행합니다. `v`로 시작하는 버전 태그를 올리면 GitHub Actions가 테스트 후 설치 파일과 업데이트 메타데이터를 초안 릴리스에 올립니다. 확인 후 릴리스를 게시하면 앱에서 감지합니다. package.json 버전과 태그는 같아야 합니다.

공개 템플릿은 예시 문구만 포함하며 원본 PPT의 글꼴·배치 리소스를 유지합니다. 성경 본문은 대한성서공회 새번역 조회를 사용합니다.
